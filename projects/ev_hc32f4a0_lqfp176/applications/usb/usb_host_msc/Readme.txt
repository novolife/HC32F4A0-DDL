平台说明
================================================================================
GCC工程，由Eclipse IDE外挂GNU-ARM Toolchain，再结合pyOCD GDB Server实现工程的编译、
链接和调试。在用Eclipse导入工程后，请将xxxx_PyOCDDebug中pyocd-gdbserver和SVD文件
设置为正确的路径；请将xxxx_PyOCDDownload中pyocd设置为正确的路径。注意，这些路径不
能包含非英文字符。

================================================================================
功能描述
================================================================================
本样例主要展示MCU USB外设实现的的USB host MSC功能。

说明：

================================================================================
测试环境
================================================================================
测试用板:
---------------------
EV_F4A0_LQ176_Rev1.0

辅助工具:
---------------------
无

辅助软件:
---------------------
串口调试助手软件（115200bps，8N1）

================================================================================
使用步骤
================================================================================
1）打开工程编译并全速运行；（如果需要调试文件系统功能，请自行添加第三方文件系统源码，并使能USB_MSC_FAT_VALID宏定义）
2）通过Micro USB口连接OTG转接线（连接口详见注意事项1），再接上U盘；
3）识别到U盘后,串口打印U盘信息；
4）如已添加文件系统源码及使能USB_MSC_FAT_VALID宏定义，则led闪烁，串口打印文件信息；
5）如已添加文件系统源码及使能USB_MSC_FAT_VALID宏定义，根据串口输出提示短按K10按键进行文件读写操作。

================================================================================
注意
================================================================================
1.本样例支持模式说明：
1）USBFS模式（连接J21）
  使能宏定义：USB_FS_MODE
  不使能宏定义：USB_HS_MODE与USB_HS_EXTERNAL_PHY
2）USBHS的FS模式（连接J19）
  使能宏定义：USB_HS_MODE
  不使能宏定义：USB_FS_MODE与USB_HS_EXTERNAL_PHY
3）USBHS模式（连接J14）
  使能宏定义：USB_HS_MODE与USB_HS_EXTERNAL_PHY
  不使能宏定义：USB_FS_MODE

2.如样例功能失败，可能由于开发板上USB外部PHY芯片状态导致，需要对开发板断电后再次运行代码。
3.运行USB主机代码时，开发板J35需要外接5V电源
