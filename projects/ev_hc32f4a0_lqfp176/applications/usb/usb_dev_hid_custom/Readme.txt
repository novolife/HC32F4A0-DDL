平台说明
================================================================================
GCC工程，由Eclipse IDE外挂GNU-ARM Toolchain，再结合pyOCD GDB Server实现工程的编译、
链接和调试。在用Eclipse导入工程后，请将xxxx_PyOCDDebug中pyocd-gdbserver和SVD文件
设置为正确的路径；请将xxxx_PyOCDDownload中pyocd设置为正确的路径。注意，这些路径不
能包含非英文字符。

================================================================================
功能描述
================================================================================
本样例主要展示MCU USB外设实现的USB HID功能。

================================================================================
测试环境
================================================================================
测试用板:
---------------------
EV_F4A0_LQ176_Rev1.0

辅助工具:
---------------------
无

辅助软件:
---------------------
串口调试助手软件（115200bps，8N1）

================================================================================
使用步骤
================================================================================
1）使用USB连接线通过评估板的USB micro口连接到PC（详见注意事项）；
2）打开工程编译并全速运行（若是可通过DAP调试，则可使用DAP自带的虚拟串口观察调试信息）；
3）点击按键K10 HID设备会通过IN端点发出按键信息，
4）在PC端使用Bus Hound通过OUT端点向设备发送数据可以控制LED的状态
   发送 0x01 0x00 熄灭红色LED
   发送 0x01 0x01 点亮红色LED
   发送 0x02 0x00 熄灭蓝色LED
   发送 0x02 0x01 点亮蓝色LED

================================================================================
注意
================================================================================
本样例支持模式说明：
1）USBFS模式（连接J21）
  使能宏定义：USB_FS_MODE
  不使能宏定义：USB_HS_MODE与USB_HS_EXTERNAL_PHY
2）USBHS的FS模式（连接J19）
  使能宏定义：USB_HS_MODE
  不使能宏定义：USB_FS_MODE与USB_HS_EXTERNAL_PHY
3）USBHS模式（连接J14）
  使能宏定义：USB_HS_MODE与USB_HS_EXTERNAL_PHY
  不使能宏定义：USB_FS_MODE
  若板子先上电运行，再通过J14接入主机：则需确保上电或复位前J24已短接（外部PHY电路接通）；
  若只通过J14对评估板进行供电，或程序开始运行时已提前通过J14接入主机，则J24无需短接。
