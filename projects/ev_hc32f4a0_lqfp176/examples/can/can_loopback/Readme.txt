平台说明
================================================================================
GCC工程，由Eclipse IDE外挂GNU-ARM Toolchain，再结合pyOCD GDB Server实现工程的编译、
链接和调试。在用Eclipse导入工程后，请将xxxx_PyOCDDebug中pyocd-gdbserver和SVD文件
设置为正确的路径；请将xxxx_PyOCDDownload中pyocd设置为正确的路径。注意，这些路径不
能包含非英文字符。

================================================================================
功能描述
================================================================================
本例程用CAN的外部回环模式进行数据的发送和接收测试，并将接收到的数据通过串口输出，可在上
位机用串口调试助手软件查看。外部回环模式下，CAN可以接收自己发出的数据，也可以接收其他
发送端发送的数据。

1. 功能说明：
   1）将‘CAN_FD_ENABLE’定义为非零，使能CAN-FD。注意，仅CM_CAN2支持CAN-FD。
2. 波特率设置，CAN-FD禁止时：
   1）系统时钟240MHz；
   2）CAN通信时钟为系统时钟的3分频，即80MHz；
   3）CAN位时间分频为通信时钟的4分频，即20MHz；
   4）CAN通信波特率为1Mbps，位时间为20TQ，采样点为75%。
3. 波特率设置，CAN-FD使能时：
   1）CAN-FD模式为 ISO CAN-FD 模式；
   2）系统时钟240MHz；
   3）CAN通信时钟为系统时钟的3分频，即80MHz；
   4）CAN-FD Nominal Bit Rate 位时间分频为通信时钟的1分频，即80MHz；
   5）CAN-FD Nominal Bit Rate 为1Mbps，位时间为80TQ，采样点为80%；
   6）CAN-FD Data Bit Rate 位时间分频为通信时钟的1分频，即80MHz；
   7）CAN-FD Data Bit Rate 为8Mbps，位时间为10TQ，采样点为80%，第二采样点为80%。
4. 接收筛选器设置：
   1）可接收任意扩展ID和标准ID的帧。
5. 发送设置：
   1）用PTB发送一帧数据，ID为标准ID 0xA1；
   2）用STB发送两帧数据，ID分别为：扩展ID 0xB2，扩展ID 0xC3。

测试环境
================================================================================

---------------------
EV_F4A0_LQ176_Rev1.0

---------------------
无

辅助软件:
---------------------
串口调试助手软件（115200bps，8N1）

================================================================================
使用步骤
================================================================================
1）用 DAP 接口调试，可以直接通过串口调试助手查看程序运行情况；
2）打开工程，重新编译，启动调试或直接下载程序运行；
3）程序将 CAN 收到的数据打印出来。
   如果是收到自己发出的数据，且校验正确，则打印：
   This is a self-transmitted frame.CAN loopback OK.
   如果校验错误，则打印：
   This is a self-transmitted frame.CAN loopback FAIL!!!. 且程序停止运行。

注意
================================================================================
CAN控制逻辑时钟（PCLK1）频率不能低于CAN通信时钟频率。
