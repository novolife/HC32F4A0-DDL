平台说明
================================================================================
GCC工程，由Eclipse IDE外挂GNU-ARM Toolchain，再结合pyOCD GDB Server实现工程的编译、
链接和调试。在用Eclipse导入工程后，请将xxxx_PyOCDDebug中pyocd-gdbserver和SVD文件
设置为正确的路径；请将xxxx_PyOCDDownload中pyocd设置为正确的路径。注意，这些路径不
能包含非英文字符。

================================================================================
功能描述
================================================================================
本例程展示了如何配置Time2的各种时钟源。
TMR2_CLK_SRC
TMR2_CLK_PIN_CLK(默认) ---> PE3 输入的方波(方波为TimerA通过PE11产生的1MHz，25%占空比的PWM)
TMR2_CLK_TRIG_RISING   ---> PA2上升沿(上升沿由TimerA通过PE11产生的1MHz，62.5%占空比的PWM提供)
TMR2_CLK_EVT           ---> 按键K10产生的事件EVT_SRC_PORT_EIRQ0
TMR2_CLK_TMR6_OVF      ---> TMR6 的上溢事件
TMR2_CLK_TMR6_UDF      ---> TMR6 的下溢事件
TMR2_CLK_XTAL          ---> XTAL 32.768KHz
TMR2_CLK_LRC           ---> LRC 32.768KHz

说明：
1. 通过“TMR2_CLK_SRC”指定Timer2的时钟源；
2. 被指定的时钟源用作Timer2的计数时钟，可用来计时、捕获或输出PWM；
3. 特别注意，在使用异步时钟源时，请严格按照用户手册所描述的注意事项进行操作。

使用步骤
================================================================================
1）打开工程，重新编译，启动调试或直接下载程序运行；
2）短接PE3与PE11，可观察到蓝灯以 1Hz 的频率闪烁。
3）将宏TMR2_CLK_SRC修改为TMR2_CLK_TRIG_RISING，
   重新编译程序，启动调试或直接下载程序运行，
   短接PA2与PE11，可观察蓝灯以 20Hz 的频率闪烁。
4）将宏TMR2_CLK_SRC修改为TMR2_CLK_EVT，
   重新编译程序，启动调试或直接下载程序运行，
   按下按键K10 5次，蓝灯亮，再按下 5次，蓝灯灭。
5）将宏TMR2_CLK_SRC修改为TMR2_CLK_TMR6_OVF或TMR2_CLK_TMR6_UDF，
   重新编译程序，启动调试或直接下载程序运行，
   可观察到蓝灯以 5Hz 的频率闪烁；
6）将宏TMR2_CLK_SRC修改为TMR2_CLK_LRC或TMR2_CLK_XTAL32，
   重新编译程序，启动调试或直接下载程序运行。
   可观察到蓝灯以 2Hz 的频率闪烁；

================================================================================
注意
================================================================================
1. 在使用异步时钟源时，请严格按照用户手册所描述的注意事项进行操作。
2. 使用 TMR6 的上溢事件或下溢事件作为 TMR2 的计数时钟时，TMR6 的时钟 PCLK0 必须与
   TMR2 的时钟 PCLK1 同频。
