平台说明
================================================================================
GCC工程，由Eclipse IDE外挂GNU-ARM Toolchain，再结合pyOCD GDB Server实现工程的编译、
链接和调试。在用Eclipse导入工程后，请将xxxx_PyOCDDebug中pyocd-gdbserver和SVD文件
设置为正确的路径；请将xxxx_PyOCDDownload中pyocd设置为正确的路径。注意，这些路径不
能包含非英文字符。

================================================================================
功能描述
================================================================================
本样例展示ETH的Loop back通信功能。

说明：
本样例配置ETH工作在PHY的loop back模式，目标板LED_BLUE亮起后，点击K2触发数据发送，
loop back将发送的数据回传回来，对接收到的数据和发送的数据进行比较，内容一致则
LED_YELLOW亮起，反之，则熄灭。

样例默认工作在MII模式（拨码开关J33拨到MII端，注释掉ethernetif.h文件中
'ETH_INTERFACE_RMII'的宏定义）；如需切换到RMII模式，需将拨码开关拨到RMII端，同时
取消ethernetif.h文件中'ETH_INTERFACE_RMII'的宏定义注释。

================================================================================
使用步骤
================================================================================
1）打开工程并重新编译；
2）启动IDE的下载和调试功能，全速运行；
3）等待目标板LED_BLUE亮起；
4）点击K2触发数据发送，并观察LED_YELLOW亮灭状态；
5）LED_YELLOW亮起则收发数据正常，反之，则通信失败。
