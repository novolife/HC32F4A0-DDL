平台说明
================================================================================
GCC工程，由Eclipse IDE外挂GNU-ARM Toolchain，再结合pyOCD GDB Server实现工程的编译、
链接和调试。在用Eclipse导入工程后，请将xxxx_PyOCDDebug中pyocd-gdbserver和SVD文件
设置为正确的路径；请将xxxx_PyOCDDownload中pyocd设置为正确的路径。注意，这些路径不
能包含非英文字符。

================================================================================
功能描述
================================================================================
本样例展示ETH的PTP中断，以及PSS0d的脉冲输出。

说明：
本样例配置ETH工作在MAC的loop back模式（该模式只能工作在MII模式），可点击K1设置目标时间，
待系统时间到达目标时间后，可观察到PG8输出20ns宽的
脉冲。

================================================================================
测试环境
================================================================================
测试用板:
---------------------
EV_F4A0_LQ176_Rev1.0

辅助工具:
---------------------
无

辅助软件:
---------------------
串口助手

================================================================================
使用步骤
================================================================================
1）连接PF0和PA1,连接PE0和PB6（通过MCO输出的时钟，灌入ETH_RX_CLK, ETH_TX_CLK）
2）用示波器连接PG8
3）打开串口助手 115200 @8N1
4）打开工程并重新编译
5）启动IDE的下载和调试功能，全速运行
6）可观察到PG8有脉冲输出
7）点击K1设置目标时间，约2s后可观察到PG8有脉冲输出
8）观察串口助手打印输出
“The PPS0 occurs interrupt.
The PTP interrupt has occurred 1 times.”其中次数与脉冲次数一致
9）重复步骤7）~8）

================================================================================
注意
================================================================================
mac回环模式，需要PHY或者其他方式给ETH_RX_CLK, ETH_TX_CLK提供时钟，本样例是系统时
钟分频后通过MCO输出（25MHz）
