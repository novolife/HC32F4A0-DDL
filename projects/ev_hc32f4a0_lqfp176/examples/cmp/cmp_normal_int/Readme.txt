平台说明
================================================================================
GCC工程，由Eclipse IDE外挂GNU-ARM Toolchain，再结合pyOCD GDB Server实现工程的编译、
链接和调试。在用Eclipse导入工程后，请将xxxx_PyOCDDebug中pyocd-gdbserver和SVD文件
设置为正确的路径；请将xxxx_PyOCDDownload中pyocd设置为正确的路径。注意，这些路径不
能包含非英文字符。

================================================================================
功能描述
================================================================================
本样例为CMP外设配置为普通比较模式时,选择CMP1_INM4(PC3)为参考电压（负端电压），
CMP1_INP4(PA3)为比较电压（正端电压），通过中断输出比较结果的样例。

================================================================================
测试环境
================================================================================
测试用板:
---------------------
EV_F4A0_LQ176_Rev1.0

辅助工具:
---------------------
直流稳压电源

辅助软件:
---------------------
无

================================================================================
使用步骤
================================================================================
1）打开工程并重新编译;
2）芯片引脚PC3连接稳压直流电源输入参考电压(<VCC)，
   测试板的PA3已连接R105变阻器的分压值作为比较电压，确认测试板上的J13已选择AVCC;
3）全速运行样例代码;
4）调节R105变阻器改变比较电压值，查看LED灯变化和PB12的VCOUT1;
5）当比较电压<参考电压，蓝色LED亮，VCOUT1输出低;
   当比较电压>参考电压，红色LED亮，VCOUT1输出高;

================================================================================
注意
================================================================================
稳压电源的输入电压不要超过VCC
